# Art direction — domain-native, high-budget

## Goal
Produce a site or interface that could not have been made for a different brand or industry, while still operating at the quality level of a strong multi-disciplinary team.

## Step 1 — Name the artifact
One sentence: “This page / product is a ___.”  
Fill it with something the actual domain already produces or would recognize.

Examples:
- Real-estate developer → property sales catalogue / brochure with floor plans and site plans
- Logistics / haulage → route book / consignment ledger / fleet status board
- Construction → site progress report / bill of quantities
- Restaurant / hospitality → tasting menu / reservation ledger
- B2B SaaS → operational workspace or audit-ready tool
- Consumer product → the tool the user actually opens to get work done

If the artifact still sounds like a camera monograph or film program when the domain is real-estate or logistics, stop and re-derive.

## Step 2 — Constraints
Extract 5–12 concrete constraints from that artifact. These become the design rules for the brief.

## Step 3 — Direction card (required)
1. Artifact / product type
2. Constraints (5+)
3. Primary object or moment (where budget and craft concentrate)
4. Type roles
5. Accent + neutral strategy

## Step 4 — Craft target
Within the domain constraints, aim for:
- Tight, intentional typography and spacing
- Considered photography / illustration / 3D / motion when the domain supports it
- One or two high-craft moments that feel expensive and specific
- Interaction details that feel designed
- Overall coherence that suggests aligned specialists

Domain-native is not an excuse for low ambition.
