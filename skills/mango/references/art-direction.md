# Art direction — domain-native method

## Step 1 — Name the artifact
One sentence: “This page is a ___.”  
The blank must be filled with something the actual domain already produces or would recognize.

Examples:
- Real-estate developer → property sales catalogue / brochure with floor plans
- Logistics / haulage → route book / consignment ledger / fleet board
- Construction → site progress report / bill of quantities
- Restaurant → tasting menu / reservation ledger
- B2B SaaS → operational dashboard or audit-ready workspace
- Consumer app → tool the user actually opens to get work done

If the artifact still sounds like a camera monograph or film program when the domain is real-estate or logistics, stop and re-derive.

## Step 2 — Constraints
Extract 5–12 concrete constraints from that artifact. These become the design system rules for the brief.

## Step 3 — Direction card (required before heavy implementation)
1. Artifact / product type
2. Constraints (5+)
3. Primary object or moment
4. Type roles
5. Accent + neutral strategy

## Step 4 — Reject defaults
- Full-bleed blurred video + centered white type
- Purple/blue glassmorphism
- Generic three-column icon feature grid
- Previous mango visual DNA on a new domain
