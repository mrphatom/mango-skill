# Verification

Work is not done when the happy path looks good.

## Minimum bar
- [ ] Direction card exists and matches the actual domain
- [ ] Anti-slop audit completed; no major tells remain
- [ ] Industry recognition + craft test passed
- [ ] Key viewports checked (mobile + desktop at minimum)
- [ ] No horizontal overflow on mobile
- [ ] Focus order and visible focus styles are sane
- [ ] Empty / loading / error states exist for data views
- [ ] Console clean of errors on primary flows
- [ ] Reduced-motion path does not break core actions

## When application-like, also
- [ ] Trust boundaries identified for new features
- [ ] Authorization considered on sensitive actions
- [ ] Forms and uploads treated as hostile input
- [ ] Critical paths have basic observability thinking

Report what was actually checked versus what was assumed.
