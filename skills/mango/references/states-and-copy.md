# States and copy

## States that are part of the product
Design and implement:
- Empty
- Loading
- Error / failure
- Success
- Offline
- Permission denied / unauthorized

Treat these with the same craft as the happy path. An empty state is an invitation to act. An error explains what happened and how to recover, in the product’s voice.

## Copy principles
- Words are design material, not decoration.
- Write from the user’s side of the screen. Name things by what people control and recognize.
- Active voice. A control says exactly what happens: “Save changes,” not “Submit.”
- Keep the same action name through the flow (“Publish” → toast “Published”).
- Sentence case. Plain verbs. No filler.
- Each element does one job. A label labels; an example demonstrates.
- Errors do not apologize and are never vague.
